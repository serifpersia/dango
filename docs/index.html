dango

A personal anime streaming tracker that keeps your watchlist, watched episodes, and sync state in one place. It focuses on local playback, queue management, and optional cloud backup through Google Drive.

What it does

  • Browse and watch anime from configured providers.
  • Track watch progress and maintain a watchlist.
  • Sync metadata across devices with Google Drive.
  • Optional tracker integrations for progress syncing.

Data and storage

By default, your data is stored locally on the machine running the app. When Google Drive sync is enabled, a small set of metadata is stored in your Drive appdata folder for syncing purposes. See the Privacy Policy for details.

Get started

Install and run dango locally. Open the app, configure providers if needed, and optionally enable sync in Settings. For Google authentication, the app requests access to Drive so it can store sync files in a private appdata folder.
